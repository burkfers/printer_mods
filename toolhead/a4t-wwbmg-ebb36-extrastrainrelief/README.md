# A4T-WWBMG-EBB36 carrier with extra strain relief

This simple mod adds additional length and zip tie loops to the ebb36 carrier
board for a4t with wwbmg.

Models with one and two additional zip tie loops, for three and four total, are provided.

If you need even more, please see the [CAD link](https://cad.onshape.com/documents/d24c118d7e73f6f898f8a909/w/25a6c77ff99de381ae14ac58/e/afb767e215f5d6ee29d3c352?configuration=Count%3D4.0&renderMode=0&uiState=69469c1cc5231a76682b04b1) and adjust the parameter as desired.
